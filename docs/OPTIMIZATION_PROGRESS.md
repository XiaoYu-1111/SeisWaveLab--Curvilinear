更新：2026-10-25，当前工作区 Release。此前打包的发布 ZIP 不会随工作区改动自动更新。

后续已接入[二维 Qp/Qs GSLS 首版](QP_QS_VISCOELASTIC_2D.md)：包含解析验证、CPU/CUDA、模型复现和六组合成试验。下文后续顺序中的介质 Q 方向现已完成二维第一阶段，三维、低存储推进、Rayleigh 定量验证及实测标定仍待开展。

## 本轮实现

| 方向 | 改动与用途 |
| --- | --- |
| 布局与交互 | 三组自定义布局、按模式保留停靠；窗口缩放和字号变化不主动重排；波场 / 空间 / 切片 / 记录可放大并用 Esc 还原 |
| 主题与材质 | 保留十二主题；新增实底、节能、完整质量档，逐面板模糊缓存及活动频率限制 |
| 界面性能 | 二维、三维推进放入单独工作线程，界面读取已完成的步、切片和接收增量；暂停在当前步结束后生效，OpenGL 留在界面线程 |
| 渲染与计时 | 静止场景复用；性能页区分推进、发布传输、场景重绘和材质刷新。按 GLFW 实际像素 / 客户区尺寸分配纹理，修正可选 viewport 比例为零时误分配 16×16 的模糊问题 |
| 数据复现 | 三维模型 schema 2 内嵌原始 DEM、间距、原点和基准；旧 schema 1 兼容；修复旧元数据长度和接收索引上限 |
| 默认地表 | 靖边南沟谷 400×288、25 m 数据随程序部署；实际 XYZ 网格按资源预算分配，原始数组保留 |
| 论文输出 | 原始记录导出白底、细线、Times 字体 SVG，可设共同幅值参考；不套用预览 AGC 或单道归一化 |
| 采集试验 | 指定目标 / 干扰波窗，导出逐道能量、RMS、比值及阈值越限到时，便于低速层、激发和接收方案受控比较 |

输出入口：“显示参数 → 论文输出与采集评价”，结果在外层 `out/exports/records`。能量为 `dt·Σv²`；RMS 按窗内实际样本数计算；零干扰能量的比值留空。阈值按本分量整道峰值比例检测，零道不产生到时。两窗必须不重叠且各有样本。阈值越限不等同于物理初至，波窗比值不等同于现场信噪比。

模型 VTS 用于复现实验输入并从 t=0 重建，不是续算检查点。本轮未改差分格式、精度、边界或接收插值。核心计时仍排除显示、暂停和导出；后台推进计时另含调度，发布计时含诊断、切片和接收增量整理，不能与核心计时重复相加。

## 验证

相关 CTest 7/7：后台发布、采集评价、二维 / 三维模型 IO、外部 DEM、动态预算、重建资源。CPU / CUDA 分别核对二维 / 三维 12 步波场和原始记录完全一致，包含二维 0.5 ms 采样、暂停、忙时重置。三维模型检查 513×257 DEM 完整往返及损坏拒绝。

`--smoke-background` 检查实际运行期间持续绘制、暂停 / 继续、放大 / 还原和场景复用，报告在 `out/validation/background`；帧数仅表示界面继续工作，不是性能基准。`--smoke-default-terrain` 检查 115200 样点保留、默认 CUDA 短步、有限性与 OpenGL 读回，报告在 `out/validation/default-terrain`；本机分配 400×288×30、25 m，其他机器可不同。

两维各十二主题 × 三模式通过，三维另检查三质量档和缓存 GL 无错。二维控件 / SEG-Y / 大模型、三维导航 / 路由 / 重建 / 七个原生窗口检查通过。本机仅一个物理显示器，跨屏混合 DPI 尚未实测。没有重跑完整数值长时回归或六档性能基准；此前报告仅代表其注明的日期、版本和算例。

## 后续顺序

1. 实验包清单：版本、设备和文件哈希；批量工况、统一幅值 / 波窗、失败记录，与模型和原始记录联合归档。
2. 用代表性模型重新量测推进、诊断、接收、切片传输和渲染，再决定静态几何 VBO、GPU 归约和异步传输，不预先承诺倍速。
3. 实测 DEM / 微测井标定；成对改变地形、低速层、源深度和道距。先做网格、边界、源宽度和时间步敏感性，再扩大三维。
4. 任意炮检点、缺道 / 变观、组合激发与频带评价；区分覆盖、照明和波窗代理指标。
5. 介质 Q、改进吸收边界及更多物理模型需要独立设计和验证；当前仍是各向同性弹性介质与侧底海绵。
