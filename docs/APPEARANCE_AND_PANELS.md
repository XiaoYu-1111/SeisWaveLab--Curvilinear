# 主题与悬浮参数面板

更新日期：2026-10-25。

主页、二维、三维共用 12 种主题。前 10 种沿用 SeisWaveLab_Process 新版的配色数值，另增加 MATLAB 风格和红黄橙。颜色与表面材质分开选择；默认使用磨砂表面。波场、高程和地震记录的科学色带仍由各视图独立设置，切换界面主题不会切换数据色带或改变数据。

| 分组 | 主题 |
| --- | --- |
| 暖色调 | 浅色砂纸、暖象牙白、杏桃暖光、玫瑰晶 |
| 中性色调 | 柔和浅玉、科研浅色、雾银灰、石墨灰 |
| 冷色调 | 冰川蓝、深海曜 |
| 应用风格 | MATLAB 浅灰蓝、红黄橙 |

MATLAB 浅灰蓝使用浅灰工作区、白色输入区域、蓝色交互强调和橙色辅助强调。红黄橙使用浅暖底色、红色主强调、黄色选中线与橙色滑块，正文使用深褐色，避免大面积高饱和背景影响阅读。建模、运行、显示和导出继续保留各自的功能提示色。

## 显示方式

三维通过“工作区 → 参数面板显示”选择；二维通过顶部“参数面板”菜单选择。

| 模式 | 行为 |
| --- | --- |
| 左侧停靠 | 保留原有参数与诊断 / 当前模拟参数标签布局 |
| 居中悬浮 | 撤去参数侧栏，绘图区使用腾出的宽度；参数在可移动、可缩放的独立悬浮面板中显示 |
| 停靠 + 悬浮并存 | 左侧与悬浮面板同时显示，可分别停留在不同功能页；参数与模拟状态共用 |

悬浮面板提供“最大化 / 还原大小”“居中”“返回左侧”按钮；关闭悬浮面板会返回左侧模式。F 或恢复默认布局也会恢复左侧模式。切换模式会重新排列主窗口中的工作区，不会重建求解器。悬浮与左侧使用同一份待应用参数，编辑后仍遵守原有应用 / 重建规则，不会创建另一套模拟。二维悬浮编辑也会暂停正在运行且参数已被修改的会话。

三维悬浮面板可继续拖出主窗口，作为原生窗口移至副屏。二维的悬浮面板位于二维主窗口内部。常规退出保存二维、三维各自的模式，下次重新进入按保存模式显示；首次显示的悬浮面板在主窗口中居中。

## 磨砂材质与显示边界

“界面外观”中可选择液态 / 磨砂表面、调整效果强度与悬停高光。居于主窗口内的悬浮参数面板和菜单使用当前帧已绘制的背景，经半分辨率、两个方向的高斯模糊后加上主题色、圆角与细微颗粒；正文和输入控件随后清晰绘制。波场、三维场景、剖面和接收图表本身保持清晰，不对求解数据做模糊。

该效果是软件内部界面的背景模糊，不是 Windows 桌面或其他应用的透明穿透。副屏原生窗口和其中的菜单使用同色的清晰材质，避免将主 OpenGL 上下文的 VAO / FBO 用于其他窗口。渲染器不可用时回退到实底面板。各视图仍共享当前求解器，独立窗口不会额外分配一套体网格或波场。

## 偏好与验证

外观偏好保存在外层 `out/ui/preferences.cfg`。新版写入稳定的 `theme_key` 和 `theme_schema 2`，按旧目录迁移此前 10 种主题编号；未知或非有限设置不会覆盖有效值。材质、强度、字号、语言和两维参数面板模式独立保存。

Release 专项命令：

```powershell
./out/bin/Release/SeisWaveLab_Curvilinear.exe --smoke-themes
./out/bin/Release/SeisWaveLab_Curvilinear.exe --smoke-2d-themes
./out/bin/Release/SeisWaveLab_Curvilinear.exe --smoke-viewports
```

前两项分别覆盖 12 种主题 × 3 种面板模式，检查实际 OpenGL 磨砂绘制、独立导航、可读性、偏好往返及模拟状态保留；三维另检查悬浮最大化 / 还原。原始截图与报告位于外层 `out/validation/themes`。多窗口验证及物理显示器数量见 `out/validation/multi-viewport/result.json`。
