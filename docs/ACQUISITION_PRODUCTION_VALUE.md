# 曲网格弹性波正演对黄土塬采集生产的意义

修订日期：2026-10-25。本文面向野外采集方案论证，区分方法潜力、当前程序能力和仍待验证的生产结论。没有以现场成本节约或资料改善比例作为已实现成果。

## 结论与适用定位

当前程序适合作为**二维近地表机理分析和采集参数初筛的数字试验工具**，再用小范围三维检查二维假设的偏差。其价值是用受控模型提出可验证的现场问题、缩小候选方案范围，不能直接替代试验炮、生产静校正、仪器/耦合标定或最终采集验收。

“传统交错网格 FD 只能使用阶梯地表”不准确。规则 Cartesian 网格上的简单台阶近似可能引入人工散射，但交错网格也有曲线坐标、浸入边界等起伏地表处理。本项目的贴体同位 MacCormack-DRP 是一种路径，不是唯一能处理起伏地表的方法。见 [Zhang 与 Chen，2006](https://doi.org/10.1111/j.1365-246X.2006.03113.x) 和 [O’Reilly 等，2022](https://doi.org/10.1785/0120210096)。

## 当前程序能做什么

| 生产问题 | 当前可执行试验 | 结果怎样使用 | 主要缺口 |
| --- | --- | --- | --- |
| 沟谷、坡坎是否改变干扰波传播 | 二维实测高程剖面，分层弹性介质，地形/源位单因素对照 | 比较固定物理窗口中的到时、能量和散射变化，形成试验线候选 | Rayleigh/转换波及海绵反射率尚需标准算例和实测验证；不能把数值伪影误作真实散射 |
| 激发层位与深度初筛 | 改变理想化力源/矩源的深度和主频，二维可选 Qp/Qs | 比较传播、分层及衰减，挑选待现场检验的深度 | 没有井孔、药柱、耦合、非线性及工区 Q 标定；不能直接给最佳药量或实物井深结论 |
| 道距、近偏移距与缺道敏感性 | 节点测线/规则面阵，改变起点/间距/道数；导出后离线删道 | 比较空间采样、有效孔径与窗内信号保留 | 当前不是任意三维点位观测系统平台，无照明/覆盖自动评价；无现场随机噪声模型，窗能量比不等于生产 S/N |
| 面波调查与模型一致性 | 导出合成记录，在外部工具提取频散并与候选 Vs 模型对照 | 为面波调查提供正演检验和多解性分析 | 没有内置 MASW 提取/反演；二维只有 P-SV/Rayleigh 相关运动，不含 SH/Love 波；不能直接生产静校正量 |

二维支持实际 X–高程剖面及可选 [Qp/Qs GSLS](QP_QS_VISCOELASTIC_2D.md)；三维支持实际米制 DEM 和参数化地形，尚无材料 Q。接收仍以规则测线/面阵为主，层表不等于任意横向 Vp/Vs/ρ 体建模。外边界海绵与材料衰减分别设置，**海绵不是地下介质 Q 吸收**。首版 Q 方法已有解析及后端验证，没有实测拟合改善证据。

记录面板“显示参数 → 论文输出与采集评价”可导出原始样本的白底细线 SVG，并设置跨工况共同幅值参考；可指定不重叠的目标 / 干扰时间窗，导出逐道能量、RMS、窗口比值和相对峰值阈值到时 CSV。窗口能量按 `dt·Σv²`，不经 AGC；能量比反映所选波窗，不自动代表现场信噪比；阈值越限不是自动物理初至拾取。相关能力适合组织低速层、主频和激发深度的受控对照，尚不能据此直接给出生产最优方案。

## 与传统交错网格 FD 的比较

| 维度 | 常规 Cartesian 交错网格实现 | 当前曲网格 MacCormack-DRP |
| --- | --- | --- |
| 适合的基准场景 | 平坦或可妥善处理地表的模型，成熟的高阶空间模板 | 可用单值高程描述的起伏自由表面、贴体剖面/体网格 |
| 地表误差 | 简单阶梯近似须检查网格与地表离散误差；改进方法可避免台阶 | 减少台阶几何近似，但仍有度量、自由边界、陡坡压缩和网格质量误差 |
| 当前本地代码 | Float32、交错速度/应力推进、CPML | Float64、交替 DRP、四阶段组合、每步诊断/回滚、海绵 |
| 比较条件 | 要求相同物理模型、源、边界目标与误差标准 | 相同节点数或相同 CFL 数值都不足以保证公平 |
| 精度判断 | 网格加密、解析/独立求解器与现场对照 | 同样需要；后端一致与运行稳定不能代替物理精度 |

本项目并未证明优于所有交错网格方法。公开研究已经存在可处理地形的交错曲网格有限差分方案：[O’Reilly 等原文](https://kbolsen.sdsu.edu/PUBL_dir/bssa-2021096.1.pdf)。

## 黄土低速层决定实际计算规模

若采用参考目标 `h ≤ Vs_min/(8×2.5×f0)`，Vs_min=250 m/s 时，30 Hz 需 h≤0.417 m，50 Hz 需 h≤0.250 m。它是采样设计起点，不是误差保证；减小 dt 无法补回空间分辨率。

因此，性能基准中 h=10 m、f0=30 Hz 的模型不应直接作为低速黄土生产精度模型。此前六档测试只用于比较当前 CPU/CUDA 实际推进成本。硬件、60 轮数据、2D/3D 耗时和倍速曲线见 [性能报告](PERFORMANCE_BENCHMARK.md)；代码已完成的证据与未完成事项见 [当前验证说明](NUMERICS_AND_VALIDATION.md)。

## 建议的现场试验闭环

1. 汇总同一工区的 DEM/测量高程、微测井、折射与面波调查、密度估计、试验炮和仪器响应；保留误差范围，不凭示例黄土层表代替实测参数。
2. 先做二维平地/起伏成对对照，分别改变沟谷几何、候选层厚/Vs、源深度、道距/近偏移距，避免多个参数同时改变导致解释混淆。
3. 对有差异的方案做网格加密、时间步/吸收层/边界距离敏感性检查。固定物理源宽度与输出采样；比较 SI 原始幅度，不用 AGC 或逐道归一化后的图做能量结论。
4. 在明确时间窗内定义指标，例如初至偏差、目标反射窗/干扰窗能量比、频带保留及删道前后记录差异；这些是试验代理指标，不等同于完整照明或生产 S/N。
5. 用独立模型/标准 Rayleigh 算例和现场小规模试验核验，再决定是否扩大三维模型或据此调整采集方案。所有炮检点避让及施工判断仍须结合现场安全和施工约束。

推荐先开展“黄土塬起伏地表下干扰波正演与采集参数敏感性分析”。井深优选需补充实测源与耦合标定；任意三维变观/照明研究需先扩展模型、观测几何和分析链。

## 面波联动的证据边界

MASW 利用 Rayleigh 波频散约束浅层剪切波结构，但频散提取受高阶模态、近源效应、频带和排列影响，不能把一条合成频散曲线当作模型唯一正确的证明。黄土场地已有改进 F-K 识别高阶/基阶模态的实测研究，但该文的具体场地厚度和结论不代表所有巨厚黄土塬。

- [Park、Miller 与 Xia（1999），MASW，USGS 收录](https://pubs.usgs.gov/publication/70021640)
- [Rayleigh-wave imaging of loess sediments，JGE（2019）](https://academic.oup.com/jge/article/16/1/77/5303855)

当前程序可提供该链条的弹性波记录输入；频散提取、反演、Vp/密度联合标定和生产静校正属于外部分析与后续验证工作。
