# 模型复现与波场数据交换

修订日期：2026 年 10 月 25 日。

## 数据对象与适用范围

| 对象 | 内容 | 读取方式 |
| --- | --- | --- |
| 二维模型 VTS | 几何、物性、全部参数、层表、外部高程样点 | 二维模型载入；从 t=0 重建 |
| 三维模型 VTS | 三维曲网格、物性、全部参数、层名、震源、接收、吸收配置和原始 DEM 数组 | 三维导出页载入；从 t=0 重建 |
| 波场快照 VTS | 当前有效步的所选速度/应力/派生标量及可选材料 | ParaView 等 VTK 软件分析 |
| 接收记录 | 每个接收位置的时间序列 | CSV 分析，二维另有 SEG-Y 导入/导出 |

两类 VTS 都是显式坐标的 VTK XML StructuredGrid，物理节点为 PointData，不含虚点。扩展名相同不代表用途相同。模型导入只接受本程序对应维度的版本化模型文件，不接受任意第三方网格、旧版波场快照或跨维度文件。模型文件未保存波场、RK 缓冲、接收历史和推进计时，不能用来从中途续算。

## 保存与载入

二维建模/导出页提供模型模块；三维位于“导出 → 可复现模型 VTS”。保存对象是当前已生效模型，有待应用修改时禁用保存。选择文件后执行载入，程序读取参数并通过同一初始化流程重建网格、度量、材料、源、阻尼和接收时间轴。

格式、维度、有限性、数组长度和数值校验通过后才建立候选会话；初始化成功后才替换旧会话。载入失败保留旧模型与结果。参考 dt 随文件保存，实际 dt 由当前核心重新计算；不把保存值强行写入求解器。CUDA 编号不作为跨机器设备标识，导入重新自动选卡，CUDA 不可用时明确改用 CPU。

保存采用临时文件写完后替换目标文件，失败时保留已有目标。自带数值完整性校验用于检测内容损坏和不一致，属于非密码学校验，不是签名或真实性证明。若外部软件修改网格或物性，不能仅保存回同一 VTS 就认为满足本程序的复现格式。

## 模型字段

坐标与数组使用 ASCII Float64、17 位有效数字、经典小数点格式。索引按 X 最快、其次 Y、最后 Z 排列。二维尺寸为 `(Nx,1,Nz)`，Y=0；三维为 `(Nx,Ny,Nz)`。坐标单位 m，Z 向下为正；物性 Vp/Vs 为 m/s，Density 为 kg/m³。

| 区域 | 二维 | 三维 |
| --- | --- | --- |
| Points | 曲面 X/Y/Z 坐标 | 三维曲网格 X/Y/Z 坐标 |
| PointData | Vp、Vs、Density、Jacobian、MetricA、MetricB | Vp、Vs、Density、LayerId、Jacobian |
| FieldData | `SeisWaveModel2DVersion`、Parameters、原始方向、层表、外部地形、采样间隔和计算设置 | `SeisWaveModel3DVersion`、`NumericalSchemeVersion`、Parameters、层表与 UTF-8 层名、深度模式、源、接收、吸收和计算设置 |

`Parameter_` 前缀对应实际参数成员。三维 `ReceiverArray` 的顺序为排列类型、X 起点、Y 起点、深度索引、X/Y 道数、X/Y 索引间隔；`AbsorbingBoundary` 为启用、X/Y/底部格数、强度。`LayersThicknessVpVsDensity` 每元组四个数；三维层名通过字节数组和长度数组保存，避免中文或 XML 特殊字符歧义。LayerId 从 0 开始，均匀模型为 0。

三维层表保留计算索引、当地埋深或基准深度三种模式。层厚表述与网格映射应联合解释，Jacobian 不是物理单元体积；本程序计算坐标以名义间距为长度尺度，节点体积权重还包含名义间距的乘积。

含 DEM 的三维模型使用 schema 2，`SurfaceGridGeometry` 依次保存 NX、NY、间距、X/Y 原点和高程基准；`SurfaceGridElevations` 保存全部原始高程，遵守 X 最快的排序。重采样后的求解坐标与原始样点同时保存并参与完整性校验。旧的无 DEM schema 1 继续兼容。读取上限按原始地表预算检查，不受旧版 65536 元数据项限制；接收位置也按实际模型尺寸校验。

## 波场分量

点击导出时默认跟随当前显示分量，跟随仅选择数组，不包含显示变换。关闭跟随可手动多选；三维还可附带 Velocity 三分量矢量和物性。未选择任何波场分量/矢量时拒绝写出并保留原文件。

| 数组 | 单位 | 定义 |
| --- | --- | --- |
| Vx、Vy、Vz | m/s | 对应方向的速度，二维没有 Vy 独立场 |
| VelocityMagnitude | m/s | 二维 `sqrt(Vx²+Vz²)`，三维速度矢量模 |
| Pressure（二维） | Pa | 平面应变下的三维平均压力 |
| MeanNormalStress（三维历史命名） | Pa | 实际为压力 `−(Sxx+Syy+Szz)/3` |
| Sxx、Syy、Szz、Sxy、Sxz、Syz | Pa | 应力张量分量，二维独立存储 Sxx/Szz/Sxz |
| Velocity（三维可选） | m/s | 每节点 `(Vx,Vy,Vz)` 三分量 |

二维无衰减时用平面应变弹性关系 `Syy=λ(Sxx+Szz)/(2(λ+μ))`；启用 GSLS 后独立积分 Syy，并由真实三正应力计算压力。压力正号与拉应力正号相反。二维模型 schema 2 另保存 `GSLSSettings`（启用、机制数、频带下限/上限、参考频率、均匀 Qp/Qs）和 `LayerQpQs`，兼容无衰减 schema 1，详见[二维黏弹性](QP_QS_VISCOELASTIC_2D.md)。

波场及坐标以 Float64 写出，保留当前有效步和实际 dt/时间，X 最快变化。不导出绘图 Float32 缓冲、显示增益、色标归一化、透明度、调色或大模型绘图步距。可选材料来自实际模型；CPU/CUDA 的同一配置采用同一空间定义。默认三参数导出接口仍输出全部传统场，显式选择接口供界面调用。

## 接收记录与采样

三维 CSV 可任意组合勾选 Vx、Vy、Vz，每个接收位置按上述分量顺序排列，列名如 `receiver_1_Vx`。文件保留源/接收坐标、单位及机制；首列为 time_s。旧接口默认 Vz 的列名仍兼容。三维每个完整有效步采样，含零时刻，N 步对应 N+1 个样点。

二维 Vx/Vz CSV 用于双分量时序分析；SEG-Y 支持分别写出分量文件。二维可选独立的 0.5/1 ms 等采样间隔，接收值由相邻有效步线性插值，求解器 dt 保持不变。波场快照始终属于当前有效求解步，不对整个波场按接收间隔插值。

模型 VTS、波场 VTS 与接收记录应联合归档，并记录软件版本、编译精度、后端设备和实际 dt。确定性检查覆盖同一实现和配置，不能据此推断任意硬件逐位一致或数值精度已收敛。
