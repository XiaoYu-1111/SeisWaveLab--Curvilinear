# DEM 横向、纵向与任意剖面提取

打开同目录的 [DEM高程剖面提取.ipynb](DEM高程剖面提取.ipynb)。Notebook 提供地形预览、区域起点平移、横向/纵向剖面位置、截取起点和长度滑条，以及 CSV 导出。支持地图单击定位起点、拖框选区和两次单击设置任意剖面端点。

## 使用

1. 在 VS Code 中打开 Notebook，选择 Python 3.10+ 内核。首次使用可运行其中的安装提示，或在本目录执行 `python -m pip install -r requirements.txt`。JupyterLab 用户同样需使用已安装这些库的内核。
2. 修改参数区的 `DEM_PATH`。当前已填写用户指定的 `3_jingbiancenter.dem` 路径；输出自动定位到项目外层 `out/dem_profiles`，也可修改 `OUTPUT_DIR`。
3. 从上到下运行，查看实际尺寸、分辨率、单位和坐标。使用 X/Y 起点偏移滑条平移区域，宽度/高度滑条调整范围；横向沿 X 增大、纵向沿 Y 增大，剖面位置以米显示。无旋转栅格以最左下像元中心作为偏移原点，避免选到数据范围外的半像元边界。
4. 用“截取起点”和“截取长度”滑条定位需要的段，终点自动同步；可用左右按钮按给定米数微移起点。默认在滑条释放后自动更新地图与剖面，也可关闭自动更新再手动点击“更新剖面”。终点数值填 0 仍表示取到末尾。
5. 点击“导出剖面结果”。导出动作会重新读取当前控件，避免参数已经修改而仍保存上次预览的结果。每次输出到独立时间戳文件夹。

当前机器已在项目外层 `out/venv-dem` 安装验证依赖，VS Code 可直接选择其中 `Scripts/python.exe` 作为内核。其他环境若遇到已有镜像的 TLS 错误，可用 `python -m pip install --index-url https://pypi.org/simple -r requirements.txt` 改走官方 PyPI；Notebook 安装提示也显式使用该地址。

同目录的 `dem_profiles.py` 提供读写和采样，`profile_selector.py` 提供一维剖面交互，`region_selector.py` 提供独立二维区域交互。换位置使用时，请保留 Notebook、这三个模块及 requirements 文件；不需要修改或重新编译波场程序。

## 二维区域高程数组导出

Notebook 第 4 节只导出一维剖面；第 9 节是独立的二维区域面板。两个面板各自持有地图、选区、参数和导出按钮，互不引用状态。二维面板支持鼠标拖框，也可精确输入 X 宽度、Y 长度和左下角偏移（米）；平移 / 缩放后点击“恢复框选”。修改宽度导致区域越界时，仅将起点移回有效范围，保留输入的尺寸。

默认居中 1 km × 1 km，按 X 点数 300 自动得到 Y 点数 300。`RUN_REGION_TEST=True` 会生成该测试集；设为 False 仅显示面板。每次“导出二维区域”将区域文件和图件统一保存到外层 `out/dem_profiles/regions/region_时间戳`，与剖面结果目录独立。

新增文件：

| 文件 | 内容 |
| --- | --- |
| `surface_grid_Nx×Ny_h间距m.vti` | VTK ImageData，规则 XY 数组，Elevation 点标量保存实际米制高程 |
| `surface_grid_Nx×Ny_h间距m.vts` | VTK StructuredGrid，单层地表，XYZ 分别为源平面坐标和实际高程 |
| `surface_grid_*_h*m_elevations.csv` | 无表头的高程矩阵，默认 **300 行 × 300 列** |
| `surface_grid_*_h*m_metadata.json` | 请求选区、实际导出范围、插值、单位、行列方向及源数据说明 |
| `surface_grid_*_h*m_map.png/.pdf/.svg` | 采样后的区域图，jet 色标位于下方 |

导出格式下拉框仅提供 **VTI + VTS、VTI、VTS**，默认同时导出。三维地表导入也只接受这两种格式。文件名示例：`surface_grid_500x400_h2m.vti`，数据、CSV、JSON、图件使用同一个含采样间隔的前缀；文件名最多显示 12 位有效数字，文件内部使用完整的 Float64 精度。

VTI 的 Z 仅一层，几何为平面 XY 图像，实际高程保存在 `Elevation` 点标量；在 ParaView 中选择 `Elevation` 使用 Warp By Scalar（Scale Factor=1、法向 +Z）得到起伏地表。VTS 直接保存 `(源 X, 源 Y, 实际高程)`，可直接查看地表。两者均含 `ElevationDatum_m`、`HorizontalSpacing_m`、米制单位与高程向上标志，导入后使用相同基准；不含该基准字段的外部文件默认取高程均值。

当前程序导入限定为单 Piece、单 Z 层、XY 等间距、单位为米的 ASCII VTI/VTS（Float64 / Float32）；不接受体模型、歪斜网格、非等距 XY 或 binary/appended/压缩数组。外部文件需先按此范围导出。体模型仍使用原有“模型 VTS”入口，不使用地表入口。

数组按 `[y][x]` 排列，第一行位于最小 Y，列沿 X 增大，保存真实高程，不减均值。三维模型使用 `Z=基准-高程`，与数组高程向上的约定相对应。

精确矩形保持原长宽，X/Y 使用同一间距，Y 点数自动计算：

| 方式 | 1000 m × 800 m 的例子 |
| --- | --- |
| 按 X 点数，不含末端（默认） | X=500 → 间距 2 m，500 × 400 点 |
| 按间距，不含末端（默认） | h=2 m → 500 × 400 点 |
| 按间距，包含末端 | h=2 m → 501 × 401 点 |

不含末端采用半开范围 `[起点,终点)`，1 km 取 500 点是 2 m 采样，节点为 0,2,…,998 m；三维实际节点跨度是 998 m，不能把选区宽度误作节点跨度。包含末端按点数时为 `L/(N−1)`；按固定间距时仅在整除长度时包含终点，不追加短间隔。非整除情形保留小于一个间距的末端余量。两类尺寸与端点规则均在面板显示并记录到 JSON。每轴 2..4096、总高程数不超过 4,000,000；超预算或不足两点时拒绝导出。

区域数组只取独立面板选区，不读取剖面选线或地图视口。NoData 拒绝整块导出，不填零、不拼接有效片段。需先确认水平长度单位；加密输出仅是插值，不提高源 DEM 真实分辨率。

独立调用：`export_surface_grid(dem, roi, OUTPUT_DIR, nx=500)`（Y 点数自动计算）；或 `export_surface_grid(dem, roi, OUTPUT_DIR, spacing_m=2, formats=("vti","vts"))`。显式 `nx=300, ny=300` 仍支持按点数比例居中内接的底层调用，UI 不使用此模式。只采样用 `sample_surface_grid`；`surface_grid_geometry` 可预检参数而不分配数组。

## 滑条与鼠标定位

常用参数与交互地图并排显示，窄窗口自动换行。精确坐标、截取终点、起点微移和采样方式收纳在“精确坐标、终点与微调”中；任意两点的端点坐标只在该方向下显示。预览采用通栏曲线，不再重复显示第二张地图，样点表默认折叠。缺少 ipympl 时，地图栏仍显示静态定位图。

### 高程曲线样式

曲线按宽幅白底、深蓝描边、浅色实线网格输出。以起点高程为默认填充参考，上方浅绿、下方浅蓝，并可标注最高 / 最低样点的位置与高程；不进行额外平滑。自然地形的峰谷宽度没有唯一界定，本工具不自动标注未经定义的宽度。

“曲线高程”可选择实际高程、相对起点、相对样点均值。后两项只改变图中的纵坐标，图题注明参考高程；均值为有效样点的算术均值。首点无效时明确使用首个有效高程，并保留无效段空缺。CSV 始终保留实际高程，显示方式与参考值另存到 `selection.json` 的 `profile_plot` 中。请求间距和最后一个实际间隔仍单独留档，不把重采样当作新增实测分辨率。

### DEM 高程地图局部放大导出

选好矩形后点击“放大到选区”，地图会真正放大到该范围；还可用工具栏缩放 / 平移。点选只作用于标有“交互地图”的画布。切换点选模式会退出工具栏导航；导航后也可点击“恢复点选”。当前内核未启用交互画布时，只显示明确标注的静态预览，不能在该图点选。Notebook 不再重复显示一张外观相似但无法定位的静态全图。

“局部 DEM 范围”有三个选择：

| 范围选项 | `dem_zoom` 的范围 |
| --- | --- |
| 自动 | 地图已缩放且视口包含选区中心时使用当前视口；否则使用选区，避免未缩放时导出仍是全图 |
| 当前地图视口 | 严格使用导出瞬间的地图范围，即使当前显示全图 |
| 选取矩形 | 严格使用当前橙色矩形范围，不受地图导航影响 |

点击“导出全部结果”时先冻结参数、有效剖面和地图背景；在独立 Agg 画布保存该背景、jet 色标、坐标范围与剖面标记，不直接对 ipympl 交互画布执行高 DPI 保存，避免影响之后的点击坐标、缩放或布局。`dem_view` 另行保留导出瞬间的当前视口，便于与 `dem_zoom` 核对。两图均不包含 Notebook 按钮、工具栏和临时点选手柄。

`dem_zoom` 和 `dem_view` 的色标水平放置在图下方，画布高度按区域横纵比例调整，减少长条区域图的上下留白；保持真实坐标比例和 jet 色标范围。交互地图与全图概览仍使用右侧色标。

**一次导出的全部结果位于同一个 `profile_时间戳` 文件夹**：DEM 全图、局部 DEM、当前地图视口、剖面曲线、可选曲线局部图、两份 CSV、`selection.json` 和 `README.txt`。每幅图均提供 600 dpi PNG 与 PDF / SVG；图形采用白底、Times New Roman、小字号细边框、内向刻度及 jet 连续色标。曲线主线 0.85 pt、基准线 0.45 pt、网格 0.35 pt，并使用较浅填充。PDF / SVG 保留文字、线条矢量，DEM 背景仍为栅格。全图中虚线框标出局部图范围。新的导出不会自动合并或移动既有历史结果。

结果先写入带 `.incomplete` 后缀的中间目录，全部成功后才发布正式目录，并在 `selection.json` 中标记 `export_status: complete`。如果写图失败，中间目录保留 `EXPORT_ERROR.txt`，界面报告失败，不会将半成品报告为完成。导出期间按钮锁定，避免重复触发；无效范围或无效剖面应修正后再导出。`map_export_request` 记录请求范围、实际采用范围和当时视口，`files` 列出本次全部文件。

交互地图未启用时，局部图按选取矩形读取原始栅格窗口绘制，并在导出提示与 `selection.json` 中注明回退方式。视口截图保留已有地图的显示分辨率，600 dpi 是输出清晰度，不增加原 DEM 的真实分辨率。普通导出需要有效的剖面数据；存在 NoData 时应先缩短剖面或明确保留最长有效段。

### 高程曲线局部放大

展开“高程曲线局部放大（可选）”，勾选“同时预览 / 导出曲线局部图”，输入放大起点和终点（米），再更新预览或导出。范围以当前截取后、实际导出的剖面起点为 0，不是相对于原 DEM 或整条未截取线。改变截取长度时会将放大范围约束到新长度；如果勾选了保留最长有效段，应按裁剪后的长度重新确认范围。

勾选后额外生成 `profile_zoom.png`、`profile_zoom.pdf` 和 `profile_zoom.svg`。放大图横坐标仍为全剖面的距离，纵坐标继续使用全剖面的显示基准，包括相对起点和样点均值；只重新调整可见区域与纵轴范围。放大边界落在两样点之间时只做相邻有效样点的线性插值，不新增实测分辨率，不跨 NoData 补值。范围与处理方式记录在 `selection.json`，CSV 内容不变。

代码调用示例：`export_profile(dem, table, metadata, zoom_range_m=(200, 400))`。直接绘制时使用 `plot_profile(table, ax, distance_range_m=(200, 400))`。

| 控件或模式 | 作用 |
| --- | --- |
| X/Y 起点偏移、区域宽度/高度 | 按距 DEM 左下像元中心的距离定位矩形，不需拖动两个范围端点才能整体平移 |
| 剖面 Y/X 位置 | 在区域内按米移动横向/纵向剖面 |
| 截取起点、截取长度、终点数值 | 相互同步，起点移动时尽量保留长度，接近边界时限制到有效范围 |
| 起点左右微移 | 按输入的米数调整起点 |
| 单击定位起点 | 将横向/纵向剖面的起点定位到点击位置，同时移动区域和剖面位置；靠边界时受数据范围限制 |
| 拖框选择区域 | 左键拖矩形更新范围 |
| 点选两个端点 | 两次单击建立任意方向剖面，自动选中整条线，再用滑条细调 |
| 启用 / 重建交互地图 | 前端重连后重新创建地图，保留当前选择 |

旧版在部分内核中出现 `'widget' is not a recognised GUI loop or backend name`。新版直接建立 ipympl 交互画布，不再调用 `%matplotlib widget` 别名，也不切换静态预览后端；地图坐标范围固定在 DEM 内，避免选择器初始图形在 `(0,0)` 附近导致大坐标图被拉远。

更新后建议**重启内核并全部运行**。若前端只显示 `Loading widget`，确认当前内核已安装 ipympl/ipywidgets，并允许相应的 Jupyter widget 扩展，随后点击重建地图。工具栏处于平移或缩放模式时暂停点选，关闭该工具后再单击定位。滑条和数值定位不依赖地图的前端鼠标事件。

## 当前 DEM 的实际适配

该文件使用 1024 字节固定记录的 USGS 风格结构，声明规则剖面、投影代码 9、水平米和垂直米。当前 GDAL USGSDEM 驱动不能直接识别此变体；模块会先尝试标准 Rasterio 读取，失败后再验证并读取该固定记录结构。它检查列编号、每列样点数、坐标对齐、范围和高程缩放，并正确处理 B 记录的继续块及南向北的样点顺序。

实际读取结果为 **1181 列 × 840 行**，间距约 **38.218514 m**；像元中心覆盖 X≈19297025.153–19342122.999 m、Y≈4142718.101–4174783.434 m。原始样点的实际高程约 **1093.6–1730.3 m**；头部包围范围为 1093–1731 m，与实际样点极值不同。原文件的 Z 分辨率为 0.1 m，读取时将原始整数乘该分辨率并加每列局部高程基准，**只处理一次**。

按用户选择，默认采用文件声明的米制平面坐标计算水平格网距离，不假定 EPSG、椭球或地理基准，不输出猜测的经纬度。这里的长度是投影平面距离，不是已完成投影改正的地面测距；高程仍保留源文件的垂直参考，没有另作大地水准面或高程基准转换。以后确认坐标系后，可明确填写 `CRS_OVERRIDE`，再选择 `geodesic` 距离模式。

兼容分支只适配经验证的无旋转、米制、规则投影代码 9 固定记录；其他 Rasterio 无法识别的变体会报错，不会静默套用错误坐标。读取过程不修改原始 DEM。兼容缓存以 Float64 GeoTIFF 保存到输出目录的 cache 下，不附加猜测的 CRS。

NoData 或范围外位置保持无效，不填成零高程，且拒绝直接导出为模拟输入。可以缩小范围，或明确勾选“只保留最长连续有效段”；后者会报告丢弃点数、保留的原始距离范围，并重新从 0 计距，不会跨空洞拼接数据。

## 与二维模拟衔接

- 实际 DEM 的约 38.2 m 像元不能因输出为 1 m 或 5 m 采样而增加真实地形分辨率。双线性插值是在已有样点间估值，不是获取更精细的实测高程。
- 在波场程序中选择 `surface_profile.csv`。对于这里约 1000 多米的实际海拔，通常以导入器默认的**高程均值**作为局部模型基准；不要把人工零高程模型使用的“基准 0 m”机械套用到实际海拔数据。CSV 的原始高程本身保持不变。
- 文件水平覆盖需满足 `(Nx−1)h ≤ 剖面长度`。例如截取恰好 1000 m，可用 Nx=401、h=2.5 m；Nz、展平深度、主频和材料仍需结合地形幅度与数值分辨率检查。
- 横向/纵向按 DEM 坐标轴定义，不等于任意旋转栅格的某一行/列，也不自动等于真东/真北；当前文件为无旋转规则米制剖面。

## 技术依据

[Rasterio 栅格读取](https://rasterio.readthedocs.io/en/stable/topics/reading.html)、[窗口读取](https://rasterio.readthedocs.io/en/stable/topics/windowed-rw.html)、[GDAL USGSDEM 说明](https://gdal.org/en/stable/drivers/raster/usgsdem.html)、[GDAL USGSDEM 读取器源码](https://github.com/OSGeo/gdal/blob/v3.10.3/frmts/usgsdem/usgsdemdataset.cpp)、[PyProj CRS](https://pyproj4.github.io/pyproj/stable/api/crs/crs.html)、[Matplotlib 矩形选择器](https://matplotlib.org/stable/gallery/widgets/rectangle_selector.html)。本模块的兼容分支是独立 Python 实现，对源记录进行校验，不向用户 DEM 写入修补后的伪投影代码。

VTI / VTS 格式依据：[VTK XML 文件规范](https://docs.vtk.org/en/latest/vtk_file_formats/vtkxml_file_format.html)。
